# Vestiário 90

Manager de futebol para navegador/PWA focado em simplicidade operacional, profundidade humana e consequências persistentes.

> Suas decisões. O mundo reage.

Fundação técnica e primeiro vertical slice do dashboard. O botão **Avançar** executa um tick determinístico da engine e o fluxo **Táticas** permite preparar e simular a primeira partida com narração textual.

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

Consulte [arquitetura](docs/ARCHITECTURE.md) e [backlog](docs/BACKLOG.md).
